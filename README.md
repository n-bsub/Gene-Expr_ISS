# Gene Expression in ISS Dust

Analysis code for: **Balasubrahmaniam N**, Nastasi N, Hegarty B, et al. *Exposure to elevated relative humidity in laboratory chambers alters fungal gene expression in dust from the International Space Station (ISS).* **Scientific Reports** 15, 28366 (2025). [https://doi.org/10.1038/s41598-025-09534-6](https://doi.org/10.1038/s41598-025-09534-6)

## Overview

This repository contains the R and Bash scripts used to analyze metatranscriptomic data from dust collected aboard the International Space Station (ISS) and incubated at three equilibrium relative humidity (ERH) levels (50%, 85%, 100%) in laboratory chambers. The study characterizes how elevated moisture alters fungal gene expression in ISS dust, with a focus on allergen production, mycotoxin biosynthesis, and secondary metabolism.

### Analyses

- **PCA and community-level statistics**: Principal component analysis of log2 CPM-transformed gene expression grouped by ERH condition and dust bag origin, with PERMANOVA (adonis2) and pairwise post-hoc testing to assess significance of ERH groupings
- **Spearman correlation**: Sample-to-sample correlation of TMM-normalized differentially expressed genes with hierarchical clustering, visualized as a heatmap
- **GO enrichment visualization**: Bubble plots of enriched Gene Ontology terms for growth-related processes and mitochondrial functions across pairwise ERH comparisons
- **Gene expression heatmaps**: ComplexHeatmap plots of TMM-normalized, log2-transformed, row-centered expression values for fungal allergen genes, aflatoxin biosynthesis genes, secondary metabolite genes, and all differentially expressed genes

## Input data

Input files (Present in `Data/` folder):

- `RSEM.gene.counts.matrix`: Trinity/RSEM gene-level count matrix from metatranscriptome assembly
- `RSEM.gene.counts.matrix.minRow10.CPM.log2.centered.PCA.prcomp.scores`: Pre-computed PCA scores from Trinity
- `diffExpr.P1e-2_C2.matrix.RDS`: TMM-normalized expression matrix for significantly differentially expressed genes (|log2FC| ≥ 2, FDR ≤ 0.01)
- `sample_text_file_HUMID_ALL.txt`: Sample-to-ERH and sample-to-Bag metadata
- GO enrichment and gene expression tables for heatmaps (tab-delimited text files in `Data/`)

Sequencing data are deposited in NASA’s GeneLab, with the identifier https://doi.org/10.26030/60zg-2n28 (GLDS-631) and https://osdr.nasa.gov/bio/repo/data/studies/OSD-701.

## Usage

1. Place input data files in the working directory or adjust `setwd()` paths in each script
2. Run the R scripts in the `Code/` folder; each is self-contained and commented with section headers
3. For the all-DE-genes heatmap, submit the SLURM shell script in `Bash scripts/` to an HPC cluster
4. Figures are saved as PDF files
